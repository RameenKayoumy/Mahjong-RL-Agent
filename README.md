# Mahjong RL Agent

A scaffold for developing and evaluating Mahjong agents using behavior cloning and proximal policy optimization (PPO).

- `mahjong_rl/` holds agent, training, evaluation, and utility modules.
- `scripts/` holds entry points for environment checks, data collection, training, and evaluation.
- `configs/` holds training configuration.
- `experiments/` and `report/` hold experiment notes and the paper draft.
- `data/`, `models/`, and `results/` hold local datasets, checkpoints, and evaluation outputs.

The Mahjong environment, agents, and training algorithms are pending implementation.
